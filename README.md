## The line

> The locals invented a holiday for gratitude, then fought over discounted rectangles the next morning. 4/5, would feast again.

One line, 125 characters. An alien tourist's review of Earth: the planet invented a holiday for gratitude, then spent the next morning fighting over discounted rectangles. The contrast is the joke, and it closes like a real review — a rating and a promise to come back for the food.

## How it works

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`. Run it with:

```sh
python3 -P -s main.py
```

Check the line without writing anything (prints the line and its length):

```sh
python3 -P -s main.py --check
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py`.
